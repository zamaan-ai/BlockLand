# BlockLand contracts (Hardhat)

Government-gated ERC-721 land records. An NFT is a registry pointer, not a legal title.

```bash
cd blockchain
npm install
npx hardhat test
npx hardhat run scripts/deploy.js --network hardhat
```

Set `SEPOLIA_RPC_URL` and `DEPLOYER_PRIVATE_KEY` to deploy to Sepolia.
